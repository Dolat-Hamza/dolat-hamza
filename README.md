I build the screens people use to work with AI agents: streaming chat, tool calls you can watch, approval steps that keep a person in control, workflow editors and SDKs that drop into any site. Four years of production work in React, Next.js and TypeScript. At Mobiz I lead a team of three developers and propose the frontend architecture for our agent products.

## See it working

<img src="assets/agui-stream.svg" alt="Animated AG-UI event stream from an agent to CopilotKit" width="100%">

My portfolio runs a live agent demo built with **CopilotKit** and a browser-side **AG-UI** agent. Frontend tools render charts in the chat, a human-in-the-loop card waits for approval, and every protocol event is shown as it happens. No AI model or API key is involved.

## Experience

**Mobiz Inc.** &nbsp;Frontend Developer, Jul 2024 to now
- Lead a team of 3 developers, mentored 2 junior developers and set up a spec-first workflow for AI-assisted development.
- Core developer of the company's production AI agent interface (Next.js 15, Electron, Turborepo).
- Built a network-operations agent UI for a global pharmaceutical client, connected to AWS Bedrock AgentCore.
- Built frontends for an AI compliance platform for Saudi banks and a multi-agent platform integrated with Dynamics 365, ServiceNow, Slack and Teams.

**CARE Pvt. Ltd. (Wiser Machines)** &nbsp;Design Engineer (Full-Stack), Aug 2022 to Aug 2024
- Built the frontend of a manufacturing scheduling and machine-monitoring platform.
- Built a real-time fleet-tracking dashboard and an Android SDK in Kotlin.
